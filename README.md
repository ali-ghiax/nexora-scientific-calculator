# Nexora

A clean Kotlin scientific calculator for Android, with history, live What-if mode, DEG/RAD, and settings.

Developed by Muhammad Ali Ghias.

## Features

- Scientific keypad: sin, cos, tan, inverse trig, log, ln, roots, powers, factorial, π, e
- Live What-if: evaluate an expression with variable `x`
- History with search, copy, and delete
- Settings: angle mode, haptic feedback, scientific keypad, dark theme
- Light cream UI with a matching dark theme

## Requirements

- Android Studio
- JDK 17
- Android SDK (compileSdk 36, minSdk 26)

## Build

Open the project in Android Studio, or run:

```bat
gradlew.bat assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/`.
